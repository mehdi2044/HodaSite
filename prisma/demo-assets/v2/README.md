# Prepared fashion demo assets

24 AI-generated demo images: 20 isolated fictional products and four fully dressed shop models. Created with the built-in Image Gen tool on 2026-10-10, then resized to 960px and encoded as WebP (quality 83). No image API is called by the storefront. Products and model compositions are illustrative, not measurements or fit guarantees. Every image is visibly disclosed as demo artwork.

The main female model wears a sand trench, white tee, beige pleated trousers, cognac tote and ivory sneakers in a warm limestone setting. Garment references for the tee, trousers, trench and bag were supplied to Image Gen to coordinate the images. Prepared looks intentionally include only the products listed in their CMS configuration; unlisted footwear/base layers are not part of a purchase.
