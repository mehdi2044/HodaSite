>
> در پروفایل مرورگر جدا، با آدرس/پورت واقعی همین کامپیوتر این صفحه‌ها را باز کن: `/fa/m/IR`، `/tr/m/TR`، `/en/m/CA`، `/admin` و `/fa/fitting-room`. مسیرهای canonical بازار از کوکی قدیمی زبان جلوگیری می‌کنند. در نوار مدیر، SHA کامل باید با بالا یکی باشد؛ زمان build، زمان واقعی build ویندوز است و آن را گزارش کن. زمان اجرای آزمایشی ابری را به‌جای زمان ویندوز ننویس.
>
> بررسی عملی: عکس‌ها/رنگ/سایز/سبد؛ یک متن صفحهٔ اصلی را از پنل ذخیره و منتشر کن و تغییر در تب ازقبل‌باز و پس از reload را ببین؛ در تنظیمات fitting دکمهٔ مستقل پروی فوری را بررسی کن. دو لباس واقعی انتخاب کن، با OTP وارد شو، ترکیب را در کمد خصوصی ذخیره و پس از reload بازیابی کن. در حساب، تم مستقیم/سایزها را ویرایش کن؛ Overview و Back/Forward باید انتخاب‌های ذخیره‌نشده را حفظ کنند، ذخیره و reload باید آن‌ها را نگه دارد. فرم شخصی نام و نام خانوادگی واقعی demo می‌خواهد؛ تغییر رنگ تم از جنسیت نتیجه‌گیری نمی‌کند.
>
> برنامه را روشن نگه دار. تحویل: لینک‌های قابل کلیک واقعی فروشگاه/مدیریت/پرو و Mailpit، روش ورود خصوصی مدیر، SHA/build UTC، نام project و فایل Compose/env **جدید**، نتیجهٔ آزمون‌ها/خطاها، و فرمان‌های دقیق start/stop فقط همین project با حفظ داده. برای توقف از stop و برای شروع از start یا up -d همان Compose/project استفاده کن؛ هیچ volume پاک نشود. اگر مانع Windows باقی ماند، اقدام دقیق لازم را گزارش کن و بازشدن سایت را فرض نکن.

در محیط ابری این چت، Docker ویندوز یا اتصال اجرای محلی مالک در دسترس نیست. بنابراین اجرای مالک و URL ویندوز **NOT_VERIFIED** و R0 آنلاین **BLOCKED_ENV** می‌مانند؛ لینک‌های loopback تست ابری، لینک قابل استفاده روی ویندوز مالک نیستند.
