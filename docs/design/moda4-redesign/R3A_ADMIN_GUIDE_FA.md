# تصویر قابل خرید و انتشار صفحهٔ اصلی — R3a

R3a پایهٔ مشترک PHOTO، پیش‌نویس خصوصی و چرخهٔ انتشار است. تمام بلوک‌های MODA4، کمپین/تخفیف/ویدیو/پاپ‌آپ و خدمات مشترک در R3b تکمیل می‌شوند. COMPOSITE تا آماده‌شدن cutout و هندسهٔ واقعی R4 قابل انتشار نیست. این تحویل تأیید نهایی ظاهر یا اجرای Windows نیست.

## مشاهده روی Windows با حفظ اطلاعات

متن [LOCAL_CODEX_PROMPT_FA.md](LOCAL_CODEX_PROMPT_FA.md) را در Codex همان Windows دارای Docker اجرا کنید. مقصد R3a در [PR70](https://github.com/mehdi2044/HodaSite/pull/70)، branch `phase/design-01-r3a-scenes-cms-preview` است؛ PR این branch و full SHA/چهار CI زنده را بخوانید و همان نسخه را pin کنید. اجرای واقعی از cloud روی Windows انجام نشده است. URL محلی فروشگاه و پنل فقط پس از مشاهدهٔ پورت/runtime همان کامپیوتر تعیین می‌شود. online R0 همچنان BLOCKED_ENV است.

قبل از cutover، backup و verify تا DB مستقل، ساخت موفق app و ops، حفظ runtime قبلی و forward migration را انجام دهید. تنظیمات، AUTH_SECRET، MFA، media، volume و داده‌های موجود حفظ شوند؛ seed/reset/down-v/prune/restore روی DB نگه‌داری‌شده اجرا نشود. مهاجرت افزایشی `20261014153000_design01_r3a_homepage_publication` دادهٔ قبلی را بازنویسی نمی‌کند.

**برگشت کد:** پس از ایجاد پیش‌نویس بازار، build قدیمی R2 انتشار را تشخیص نمی‌دهد و ممکن است ردیف پیش‌نویس را جای fallback بخواند. فقط به build سازگار با خوانندهٔ R3 برگردید؛ بازگشت به R2 را rollback سازگار فرض نکنید. schema، revisionها و media را نگه دارید؛ دیتابیس/سفارش‌های جدید را از backup عقب نبرید. پیش از ساخت دادهٔ R3، runtime قبلی برای recovery شکست راه‌اندازی نگه داشته شود.

## کار مدیر

1. با password و MFA فعلی وارد پنل شوید؛ از صفحهٔ اصلی پنل، «تصاویر قابل خرید» را باز کنید (`/admin/content/homepage/scenes`). دامنهٔ واقعی بازار یا همهٔ بازارها را انتخاب کنید. اجازهٔ خواندن و نوشتن در سرور مستقل بررسی می‌شود.
2. جای بنر موجود یا تصویر اصلی جدید را انتخاب کنید. تصویر READY جدا برای موبایل/دسکتاپ، قاب contain/cover، نسبت و focal را تنظیم کنید. عنوان/توضیح در fa/tr/en مستقل‌اند.
3. هر لباس عرضه‌شده را از محصول، رنگ نام‌دار و عکس مرجع **همان رنگ** انتخاب کنید. عکس عمومیِ محصول چندرنگ به‌عنوان مرجع قطعی رنگ پذیرفته نمی‌شود. سایز پیشنهادی، خرید خودکار نیست؛ مشتری سایز واقعی را انتخاب می‌کند. نام کوتاه برچسب اختیاری است؛ مبلغ همیشه از کاتالوگ می‌آید.
4. جای هر برچسب را روی عکس بکشید، با کلید جهت جابه‌جا کنید یا x/y را وارد کنید. مختصات مربوط به پیکسل عکس‌اند و با RTL معکوس نمی‌شوند. موبایل و دسکتاپ جدا تنظیم می‌شوند. قیمت‌ها در فهرست کنار تصویر همیشه قابل خواندن‌اند. قاب preview واقعاً 390 یا 1280 CSS px است؛ در پنل باریک، داخل بخش preview پیمایش کنید.
5. PHOTO پیکسل لباس را با عوض‌کردن شناسه تغییر نمی‌دهد. عکس سازگار انتخاب کنید و پس از بررسی واقعی همهٔ لباس‌ها، تطبیق را تأیید کنید. این تأیید از مبلغ/موجودی مستقل است؛ تغییر لباس، رنگ یا رسانه به تطبیق تازه نیاز دارد. عکس نمونه، اثبات تطبیق کالای واقعی نیست.
6. پیش‌نمایش ذخیره‌نشده، خصوصی و فقط خواندنی است. بازار، زبان و قاب آن را تغییر دهید؛ سبد فعال نمی‌شود. ذخیرهٔ پیش‌نویس، صفحهٔ منتشرشده را تغییر نمی‌دهد. پس از ذخیره، reload پنل را برای حفظ مقدار بررسی کنید.
7. نسخهٔ تاریخچه را انتخاب و پیش‌نمایش آن را باز کنید؛ بازکردن نسخه آن را ذخیره یا منتشر نمی‌کند و فرم تاریخچه فقط خواندنی است؛ برای ویرایش به پیش‌نویس فعلی برگردید. «انتشار نسخهٔ انتخاب‌شده» محتوا را با نسخه/مجوز/مراجع فعلی دوباره بررسی می‌کند. بازگردانی همان انتشار نسخهٔ قدیمی معتبر است و سفارش، موجودی یا دفتر مالی را برنمی‌گرداند.
8. زمان‌بندی با UTC روشن ثبت می‌شود. زمان اجرا دوباره مجوز، نسخه و رسانه/کاتالوگ بررسی می‌شوند. شکست برنامه‌ریزی در پنل و queue/alert دیده می‌شود؛ نسخهٔ قبلی باقی می‌ماند. رقابت دو ویرایش با یک version، فقط یک برنده دارد؛ تعارض را بازخوانی و حل کنید.
9. فروشگاه بازِ مدیر در build preview پس از انتشار/focus تازه می‌شود؛ برگهٔ مخفی polling نمی‌کند. قیمت/stock صحنهٔ قابل مشاهده و preview از resolver واقعی به‌روز می‌شوند. برای بازدیدکنندهٔ عادی، صفحهٔ تازه بارگذاری‌شده انتشار را می‌خواند. مبلغ ناموجود صفر/دلار ساختگی نیست. افزودن کامل فقط پس از انتخاب همهٔ سایزها و quote/stock تازه انجام می‌شود.

سقف ایمنی PHOTO دوازده قلم است؛ سقف چهار قلمِ پرو/ست آماده تغییر نکرده. رسانهٔ خراب یا تطبیق نامعتبر، خرید صحنه را متوقف و مسیر کاتالوگ را حفظ می‌کند. مجوز merge، هزینه یا استفاده از AI جدید داده نشده است.
