### اصول UX ادمین
- زبان ادمین قابل انتخاب (فارسی پیش‌فرض برای مهدی، انگلیسی هم کامل).
- هر فرم: ذخیره + «ذخیره و ادامه»، اعتبارسنجی واضح، پیام موفقیت.
- پیش‌نمایش زنده برای Theme/Homepage/Pages در موبایل و دسکتاپ.
- تغییرات خطرناک (ریستور، حذف بازار، تغییر نرخ ارز دستی) تأیید دومرحله‌ای.
- جست‌وجوی سراسری در بالای ادمین (سفارش، مشتری، محصول).

## بخش B — راهنمای ظاهر و هویت بصری فروشگاه

ظاهر برای مالک پروژه **بسیار مهم** است. هدف: حس یک برند مد premium و آرام؛ نه فروشگاه شلوغ حراجی و نه اپ فنی.

### تم پیش‌فرض (قابل تغییر از ادمین)
- پس‌زمینه: سفید گرم `#FBF8F3` / سطح: `#FFFFFF`
- متن اصلی: `#1A1A1A` / ثانویه: `#6B6B6B`
- برند (نارنجی طبق اسلایدها): `#E8792A` / hover `#D06A20`
- کرم/شنی برای کارت‌ها و بنرها: `#F1E9DD`
- موفق `#2E7D4F`، خطا `#C0392B`، هشدار `#B7791F`
- گردی: ۱۲px کارت، ۹۹۹px دکمه (pill)
- فونت: Vazirmatn (fa) با اعداد فارسی، Inter (en/tr)؛ تیترها سنگین‌تر و کمی فشرده
- فاصله‌گذاری سخاوتمندانه؛ عکس محصول همیشه قهرمان صفحه؛ نسبت تصویر ۳:۴

### الگوهای صفحات (موبایل اول)
- **خانه:** Hero تمام‌عرض با عکس فصل + یک CTA → سه کارت زنانه/مردانه/بچگانه → جدیدترین‌ها (اسکرول افقی) → کالکشن فصل → نوار اعتماد → فوتر با انتخاب زبان/بازار.
- **دسته:** فیلترهای کشویی پایین صفحه (سایز، رنگ، قیمت، برند، موجودی)، مرتب‌سازی، گرید ۲ ستونه موبایل / ۴ ستونه دسکتاپ، Load more.
- **محصول:** گالری swipe با نقاط، عنوان + قیمت به ارز بازار (+ «شامل/بدون مالیات» طبق تنظیم)، انتخاب رنگ (دایره‌های رنگی) و سایز (chip)، نشان موجودی، دکمهٔ Sticky «افزودن به سبد»، راهنمای سایز (Sheet)، تب‌های توضیحات/مشخصات/نگهداری/ارسال و بازگشت، محصولات مشابه.
- **سبد/Checkout:** ۳ مرحلهٔ واضح با نوار پیشرفت: اطلاعات → ارسال و هزینه‌ها (Breakdown شفاف) → پرداخت (کارت بانکی بازار + آپلود فیش). خلاصهٔ سفارش چسبان در دسکتاپ.
- **حساب کاربری:** سفارش‌ها با Timeline وضعیت، آدرس‌ها، علاقه‌مندی‌ها، زبان/بازار.
- **ادمین:** سایدبار جمع‌شونده، کارت‌های KPI، جداول با فیلتر/ذخیرهٔ فیلتر، صفحهٔ سفارش با Timeline و فیش قابل زوم.

### قواعد سخت
- هیچ صفحه‌ای بدون حالت loading / خالی / خطا تحویل نمی‌شود.
- RTL واقعی: آیکون‌های جهت‌دار آینه می‌شوند، اعداد فارسی، تاریخ شمسی در fa.
- **قانون BiDi (V-2، الزامی):** هر قطعهٔ متن لاتین/عددی که داخل متن فارسی می‌آید باید ایزوله شود، وگرنه ترتیب نمایش به‌هم می‌ریزد (مثلاً `SH-MW-1023` یا IBAN وسط جمله). یک کامپوننت مشترک `<Iso>` (رندر `<bdi dir="ltr">`) ساخته می‌شود و **اجباری** است برای: SKU، بارکد، شمارهٔ سفارش، شمارهٔ فاکتور، IBAN/شبا/شمارهٔ کارت، شمارهٔ رهگیری، ایمیل، URL، نام فایل، کد کوپن، شناسهٔ تراکنش، نسخهٔ نرم‌افزار و هر رشتهٔ کد. در CSS از `unicode-bidi: isolate` و properties منطقی (`margin-inline-start` و …) استفاده می‌شود، نه `left/right`. تست: یک تست Playwright که در فارسی، `کد کالا: SH-MW-1023 موجود است` را رندر و ترتیب کاراکترها را با snapshot چک می‌کند.
- Touch target حداقل ۴۴px. کنتراست AA.
- عکس‌ها lazy + blur placeholder؛ LCP موبایل ≤ ۲.۵s.
- بدون Dark Pattern: تخفیف ساختگی، تایمر فیک، اجبار عضویت ممنوع.
