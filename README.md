# HodaSite — فروشگاه پوشاک سه‌زبانه (نام نمایشی موقت: STYLE HUB)

> نام برند، لوگو، رنگ‌ها و همهٔ متن‌های سایت از پنل ادمین قابل تغییرند. «STYLE HUB» فقط یک نام موقت برای شروع کار است.

فروشگاه آنلاین پوشاک زنانه / مردانه / بچگانه با فروش در **ایران، ترکیه و کانادا** و رابط کاربری **فارسی، ترکی و انگلیسی**.

## این مخزن چطور کار می‌کند؟

چرخهٔ فعال طبق D70؛ مرجع: [وضعیت معتبر تصمیم‌ها](docs/02_DECISIONS.md#current-policy).

| نقش | مسئولیت |
|---|---|
| مهدی، مالک محصول | هدف تجاری، دامنهٔ محصول، بازخورد تجربهٔ واقعی و اختیار نهایی مرج؛ اجازهٔ صریح مهدی برای هر مرج لازم است. |
| وی‌بانو / عامل اجرایی | مدیریت فنی، پیاده‌سازی، بررسی کیفیت و تست؛ Codex هرگز PR خودش را مرج نمی‌کند. |

تأیید یا همکاری پیکسل شرط کار نیست. بررسی خودکار GitHub و خودبازبینی با عنوان واقعی گزارش می‌شوند؛ بازبینی مستقل انسانی ادعا نمی‌شود مگر انجام شده باشد. branch + PR و سه CI لازم حفظ می‌شوند.

## چرخهٔ کار هر فاز

1. عامل اجرایی تصمیم‌های جاری و شرح فاز را می‌خواند و روی برنچ جدا کار می‌کند.
2. PR همیشه ابتدا Draft ساخته می‌شود؛ Ready for Review فقط پس از تکمیل پیاده‌سازی، push همهٔ commitهای موردنظر و موفقیت بررسی‌های محلی لازم.
3. مرج طبق D70 فقط با CI لازم سبز روی head فعلی، آخرین `[HODASITE-AI-REVIEW]` بدون blocker برای همان SHA، حل گفتگوهای مسدودکننده و اجازهٔ صریح مهدی ممکن است. Ready یا self-review مجوز مرج نیست.
4. پذیرش واقعی گوشی/لپ‌تاپ و محیط staging طبق D51 جداگانه ثبت می‌شود؛ CI جای آزمون اجرا‌نشده را نمی‌گیرد. این پذیرش جدا از اجازهٔ صریح مرج طبق D70 است.
