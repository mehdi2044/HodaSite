# HodaSite — فروشگاه پوشاک سه‌زبانه (نام نمایشی موقت: STYLE HUB)

> نام برند، لوگو، رنگ‌ها و همهٔ متن‌های سایت از پنل ادمین قابل تغییرند. «STYLE HUB» فقط یک نام موقت برای شروع کار است.

فروشگاه آنلاین پوشاک زنانه / مردانه / بچگانه با فروش در **ایران، ترکیه و کانادا** و رابط کاربری **فارسی، ترکی و انگلیسی**.

## این مخزن چطور کار می‌کند؟

چهار نقش داریم (D34):

| نقش | چه کسی | وظیفه |
|---|---|---|
| **مالک / رئیس پروژه** | مهدی | تصمیم نهایی، تست پذیرش در Checkpointها، Merge هر فاز |
| **پیکسل** — مدیر پروژه / مالک معماری | Claude | نوشتن و نگهداری این اسناد، تعریف فازها، بازبینی کار مکس، حل مشکلات |
| **وی‌بانو** — بازبین مستقل / Quality Gate | ChatGPT | نقد تصمیم‌های معماری و بازبینی هر PR قبل از Merge؛ نظر دوم |
| **مکس** — برنامه‌نویس | Codex | اجرای هر فاز دقیقاً طبق `docs/phases/` و قوانین `AGENTS.md` |

## چرخهٔ کار هر فاز

1. مهدی متن آمادهٔ `docs/prompts/phase-XX.md` را در Codex (مکس) پیست می‌کند.
2. مکس فاز را می‌سازد، تست‌های خودکار می‌نویسد، `docs/PROGRESS.md` را به‌روز می‌کند و Pull Request می‌دهد.
3. پیکسل گزارش PR را بازبینی می‌کند؛ سپس وی‌بانو نظر دوم می‌دهد. اگر لازم شد اصلاحیه به مکس داده می‌شود.
4. در پایان هر **Checkpoint** (هر ۲ تا ۳ فاز) مهدی چک‌لیست `docs/08_TEST_CHECKPOINTS_FA.md` را روی سایت واقعی (staging) تست می‌کند.
5. تأیید مهدی → فاز بعد.

## شروع سریع

- اگر برای اولین بار اینجا هستید: `docs/00_INDEX.md` را باز کنید.
- برای نصب روی کامپیوتر یا سرور: `docs/07_SETUP_GUIDE_FA.md`.
- برای دادن کار به Codex: `docs/prompts/phase-00.md` را کپی کنید.
